# Query policies and native audit times

This implementation compares separately chosen query orders under the same reference admissions and source-contract identity rule. Joint comparison prioritizes either the total independent contribution or the shared difference coefficient. This directory also retains the next-step minimax conditional baseline and the common-remainder conditional ablation. The current paired conditional implementation, adaptive selection and serial timing are in `studies/conditional/`.

The retained evidence is in `../../../results/comparisons/`. It contains the full query traces, exact hindsight certificate sizes, record-admission controls, and two complementary method-order blocks of native execution. The current publication selects the joint-target observations from those blocks and combines them with the separately received paired-conditional timing block. It excludes the old common-remainder conditional timings and all correctness-validation durations from the current timing table. `verify.py` independently reconstructs query selection, bounds, raw observation admission, and the published summaries. `native_timing.py` and `native_timing_reverse.py` execute fresh comparison audits; their output directories must be new.

Run `python3 -B -S artifact/check.py --scope primary` from the project root to receive the recorded study. Run a producer through `artifact/run.py` to save new measurements separately. The paper's supplementary methods describe which stages enter the measured audit time and which preparation work is common to both methods.
